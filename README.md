# M365-QuickAssess Launcher

Entry point script for [M365-QuickAssess](https://www.powershellgallery.com/packages/M365-QuickAssess) — a read-only Microsoft 365 tenant assessment tool built by [Rackspace Technology](https://www.rackspace.com).

---

## Usage

### Step 1 — Download the launcher

**[⬇ Download Launch-M365Assessment.ps1](https://raw.githubusercontent.com/HennepinCrawler/M365-QuickAssess-Launcher/main/Launch-M365Assessment.ps1)**

Save it to your Desktop.

### Step 2 — Unblock the file

Right-click `Launch-M365Assessment.ps1` → **Properties** → check **Unblock** → **OK**.

### Step 3 — Run

Right-click `Launch-M365Assessment.ps1` → **Run with PowerShell**.

The launcher will handle everything — PowerShell 7, all dependencies, and the assessment itself.
